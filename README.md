# Storeroom

Website and help pages for **[Storeroom](https://nkiro33.github.io/storeroom/)**, a browser extension that backs up every product in your Teachers Pay Teachers store and exports it to Shopify, WooCommerce, Pinterest, Etsy and more. It runs privately in your browser.

Get it for [Chrome](https://chromewebstore.google.com/detail/nmfblnbdbphkchoggcbmedejegikmcem), [Edge](https://microsoftedge.microsoft.com/addons/detail/lgbofabfmceceknhdinjmoidhicbokeg) or [Firefox](https://addons.mozilla.org/firefox/addon/storeroom-tpt-backup/). Pro is on [Gumroad](https://neblaze4.gumroad.com/l/storeroom).
